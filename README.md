# Vending Machine Design Using Verilog HDL

## Description
Designed a Vending Machine using Verilog HDL based on a Finite State Machine (FSM) in Xilinx Vivado. The design accepts ₹5 and ₹10 coins, dispenses the product when the required amount is reached, and returns extra money as change.

## Key Concepts Used
- **Finite State Machine (FSM):** Implemented a 3-state FSM to control vending machine operations.
- **Sequential Logic Design:** Used clock-based sequential logic for state updates.
- **State Transition:** Implemented transitions between states based on coin inputs.
- **Clock and Reset:** Used clock and reset signals for controlling the operation.
- **Coin Input Processing:** Recognized ₹5 and ₹10 coin inputs.
- **Product Dispensing:** Generated a dispense signal when the required amount was reached.
- **Change Return Mechanism:** Implemented logic to return extra money.
- **Testbench Verification:** Verified the design by applying input signals and observing outputs.
- **Simulation and Waveform Analysis:** Used Vivado simulation to observe and verify circuit behavior.

## Tools Used
- Xilinx Vivado
